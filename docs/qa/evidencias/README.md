# Evidencias de la matriz del Sprint 2

Capturas de las variantes de [`../matriz-sprint2.md`](../matriz-sprint2.md).

- **Nombre:** `<ID>-<estado>.png`, en minúsculas. Por ejemplo `C10.1-pasa.png` o `R4.2-falla.png`. Si hay varias de la misma variante: `C10.12-falla-2.png`.
- **Formato:** PNG o JPG de menos de 500 KB. Los videos van adjuntos al Bug de Azure, no aquí.
- **Nunca** pueden mostrar tokens (el campo *Authorize* de Swagger, una cabecera `Authorization`), llaves (Maps, Firebase), contraseñas ni URLs de base de datos. Si aparece uno, recorta la imagen o vuelve a tomarla.
- Después de agregar la captura, escribe su nombre en la columna **Evidencia** de la variante.
